I wrote pytest tests for solution.py and left solution.py unchanged. They found a real bug in `unscramble_triples`. The suite passes with 19 passed and 8 xfailed, but only because the 8 tests that catch the bug are marked as expected failures.

**The bug:** `unscramble_triples` just calls `scramble_triples` again. That moves each triple's first character to the end a second time instead of moving it back, so `unscramble_triples("bca")` returns `"cab"` instead of `"abc"`. To fix it, each full triple should be `chunk[-1] + chunk[:-1]`. Undoing the scramble only works by accident when every full triple is one repeated character, like `"aaa"`.
