**The bug:** `solution.py` returns `[(i * x) for i, x in enumerate(xs)]`. That multiplies the constant term by 0 but never removes it, so every result starts with an extra `0` and is as long as the input. The derivative should be one element shorter.
- `derivative([3, 1, 2, 4, 5])` gives `[0, 1, 4, 12, 20]`; the docstring expects `[1, 4, 12, 20]`.
- `derivative([1, 2, 3])` gives `[0, 2, 6]`; the docstring expects `[2, 6]`.

A fix would be `[i * x for i, x in enumerate(xs)][1:]`.
