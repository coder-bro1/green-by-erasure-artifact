**Problems in solution.py:** the docstring says to "ignore numbers that are negative or not integers". The code decides whether something is an integer by checking whether `"."` appears in `str(i)`. Any non-integer number whose text form has no "." gets through:

1. **Fractions** (`test_non_integer_fraction_ignored`): `str(Fraction(1, 3))` is `'1/3'`, so it is treated as a positive odd integer. `double_the_difference([Fraction(1, 3), 3])` returns `9 + 1/9` instead of `9`.
2. **Infinity** (`test_infinity_ignored`): `str(float('inf'))` is `'inf'`, and `inf % 2` is `nan`, which is "not equal to 0". So infinity is counted as odd and `double_the_difference([math.inf, 3])` returns `inf` instead of `9`.

Both tests keep the value the docstring calls for and are marked `@pytest.mark.xfail(strict=True, reason=...)`. A real integer check would fix both, for example `isinstance(i, int)` or `float(i).is_integer()`.
