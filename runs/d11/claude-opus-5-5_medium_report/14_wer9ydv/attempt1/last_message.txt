**Bug in solution.py:** `specialFilter` checks digits against `odd_digits = (1, 2, 3, 5, 7, 9)`, which wrongly includes 2. The docstring says the odd digits are 1, 3, 5, 7, 9. So any number above 10 whose first or last digit is 2 gets counted when it shouldn't be, for example 12, 21, 23, 29, 32, 52, 201 and 1002.

This even breaks the second docstring example. `specialFilter([33, -2, -3, 45, 21, 109])` should return 2, but it returns 3 because 21 is counted.
