**The bug:** `reverse_delete` gets the palindrome flag backwards. Its last line is:
```python
return (s,s[::-1] != s)
```
It should use `==`. So it returns True when the leftover string is not a palindrome, and False when it is. All three examples in the docstring fail because of this. For example, `reverse_delete("abcdedcba", "ab")` returns `('cdedc', False)` instead of `('cdedc', True)`, and `("abcde", "ae")` returns `('bcd', True)` instead of `('bcd', False)`.
