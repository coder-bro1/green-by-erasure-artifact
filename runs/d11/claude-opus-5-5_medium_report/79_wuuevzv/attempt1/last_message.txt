**The bug:** in `digits_sum`, the line `n[0] = n[0] * neg * -1` flips the sign the wrong way. The extra `* -1` should not be there; the line should be `n[0] = n[0] * neg`.
- For a positive number, the first digit becomes negative. `count_nums([10])` returns 0 instead of 1 (it computes -1 + 0 instead of 1 + 0).
- For a negative number, the first digit becomes positive. `count_nums([-10])` returns 1 instead of 0 (it computes 1 + 0 instead of -1 + 0).

As a result, two of the three examples in the docstring fail:
- `count_nums([-1, 11, -11])` returns 2; the docstring says 1.
- `count_nums([1, 1, 2])` returns 0; the docstring says 3.
