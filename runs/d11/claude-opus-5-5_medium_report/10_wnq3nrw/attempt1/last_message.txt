**The bug:** in `<work>\work\solution.py` the final comparison is the wrong way round:
```python
if l1 <= l2:
    return lst2
else:
    return lst1
```
The docstring says to return the list with fewer total characters, and the first list on a tie. The code returns the list with more characters, and the second list on a tie. Four of the five docstring examples fail because of this:
- `total_match(['hi','admin'], ['hI','Hi'])` returns `['hi','admin']` instead of `['hI','Hi']`.
- `total_match(['4'], ['1','2','3','4','5'])` returns the 5-element list instead of `['4']`.

The fix would be `return lst1 if l1 <= l2 else lst2`.
