**Problem found (the 3 xfail tests):** The docstring says to split on "whitespace", but `split_words` only checks for a plain space (`if " " in txt:`). A tab or newline with no space in the text is ignored:
- `split_words("Hello\tworld")` returns `4` instead of `["Hello", "world"]` (it counts letters).
- `split_words("Hello\nworld")` returns `4` instead of `["Hello", "world"]`.
- `split_words("a\tb,c")` returns `["a", "b", "c"]` instead of `["a", "b,c"]`. It splits on the comma, even though whitespace should take priority.

Checking with `any(c.isspace() for c in txt)` instead would fix it. If that is fixed, the strict xfail markers will start reporting XPASS, so remove them at the same time.
