**The bug:** the second loop in `solution.py` should run over `counts` but runs over `arr`:
```python
for i, count in enumerate(arr):      # should be enumerate(counts)
    sorted_arr.extend([i] * count)
```
So `bucketsort([0], 1)` returns `[]` instead of `[0]`, and `bucketsort([1, 1], 2)` returns `[0, 1]` instead of `[1, 1]`.
