**The bug:** when the first characters match, it adds 1 when it should add 0:
```python
elif source[0] == target[0]:
    return 1 + levenshtein(source[1:], target[1:])   # should be: return levenshtein(source[1:], target[1:])
```
What it returns now:
- Identical strings give their length instead of 0, e.g. `levenshtein('abc','abc') == 3`.
- kitten / sitting gives 7 instead of 3.
- The docstring's own example, electron / neutron, gives 8 instead of 3.
