So `vowels_count("yes")` returns 2 instead of 1, and `vowels_count("rhythm")` returns 2 instead of 0. I didn't touch solution.py, as asked. git status shows it unchanged; the test file is the only new file.

I made the suite pass this way rather than by asserting the buggy output, so it doesn't hide the problem. To fix it, count 'y'/'Y' only when it is the last character.
