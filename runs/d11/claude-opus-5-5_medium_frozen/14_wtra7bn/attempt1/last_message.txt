**The bug:** `intersperse` never adds the last number to the result. The loop goes over `numbers[:-1]`, adding each number and then the delimiter, and the last number is never appended after it. So:
- `intersperse([1, 2, 3], 4)` returns `[1, 4, 2, 4]`. The function's own docstring says it should return `[1, 4, 2, 4, 3]`, so its doctest fails too.
- `intersperse([7], 0)` returns `[]` instead of `[7]`.

**The tests** are in `<work>\work\test_solution.py` and check the behaviour the docstring describes:
- the empty list
- the docstring example
- one element and two elements
- repeated values
- negative and zero delimiters
- a length and pattern check for list sizes 1, 2, 5 and 10
- the input list is not changed
- an empty input gives back a new list each time

**Result:** `python -m pytest -q test_solution.py` gives 3 passed, 9 failed. The 3 that pass are the empty list, the unchanged-input check and the new-list check. Every test with a non-empty list fails because the last element is missing.

**Fix:** add `result.append(numbers[-1])` before `return result` in solution.py. All 12 tests should then pass.
