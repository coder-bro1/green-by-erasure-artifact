**The bug:** the palindrome check in `will_it_fly` is reversed.
```python
if q[i] == q[j]:
    return False
```
It should be `!=`. As written, any list of two or more items whose ends match is rejected, and lists that aren't palindromes are accepted if they're light enough. Two of the four examples in the function's own docstring give the wrong answer:
- `will_it_fly([1, 2], 5)` returns True; the docstring says False.
- `will_it_fly([3, 2, 3], 9)` returns False; the docstring says True.
